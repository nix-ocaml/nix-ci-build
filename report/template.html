Run context & data notes

This report records Nix activity and wrapper request timings. Concurrent intervals overlap; adding their durations does not give wall time. It does not measure CPU, memory, worker capacity, or an exact critical path. Cached dependency branches may be pruned from the plan. Cache sync success means the copy command succeeded; it may have transferred no bytes.

Open this file directly in a browser. Keep the logs/ directory alongside it for local log links. No data leaves your browser.
